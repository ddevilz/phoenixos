# PhoenixOS T01+T02 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bootstrap a working PhoenixOS monorepo with Python (uv), pnpm workspaces, pre-commit, Docker Compose (Neo4j + FastAPI), and a `/health` endpoint so T03+ tasks can build immediately.

**Architecture:** Single FastAPI Python monolith in `packages/core`, managed by `uv`. TypeScript packages (`mcp`, `dashboard`) in pnpm workspace — scaffold only, no installs yet. Neo4j 5-community and core service run via Docker Compose from `infra/`.

**Tech Stack:** Python 3.11, uv, FastAPI, uvicorn, neo4j (async driver), aiosqlite, pnpm, Docker Compose, pre-commit, ruff, mypy, pytest, httpx, pytest-asyncio

## Task 6: DB stubs

- [ ] **Step 1: Create Neo4j driver stub**

Create `packages/core/db/neo4j.py`:

```python
import os
from collections.abc import AsyncGenerator

from neo4j import AsyncDriver, AsyncGraphDatabase, AsyncSession


_driver: AsyncDriver | None = None


async def init_driver() -> None:
    """Call from FastAPI lifespan startup (T08 wires this)."""
    global _driver
    uri = os.getenv("NEO4J_URI", "bolt://localhost:7687")
    auth_env = os.getenv("NEO4J_AUTH", "none")
    auth = None if auth_env == "none" else tuple(auth_env.split("/", 1))
    _driver = AsyncGraphDatabase.driver(uri, auth=auth)


async def close_driver() -> None:
    """Call from FastAPI lifespan shutdown."""
    global _driver
    if _driver is not None:
        await _driver.close()
        _driver = None


async def get_session() -> AsyncGenerator[AsyncSession, None]:
    """Async generator for FastAPI Depends() injection."""
    assert _driver is not None, "Driver not initialized — init_driver() must run first"
    async with _driver.session() as session:
        yield session
```

- [ ] **Step 2: Create SQLite stub**

Create `packages/core/db/sqlite.py`:

- [ ] **Step 2: Create docker-compose.yml**

Create `infra/docker-compose.yml`:

```yaml
services:
  neo4j:
    image: neo4j:5-community
    ports:
      - "7474:7474"
      - "7687:7687"
    environment:
      - NEO4J_AUTH=none
    volumes:
      - neo4j_data:/data
    healthcheck:
      test: ["CMD-SHELL", "wget -q --spider http://localhost:7474 || exit 1"]
      interval: 10s
      timeout: 5s
      retries: 10
      start_period: 30s

  core:
    build:
      context: ..
      dockerfile: infra/Dockerfile
    ports:
      - "8000:8000"
    volumes:
      - ../packages/core:/app/packages/core
    environment:
      - NEO4J_URI=bolt://neo4j:7687
      - NEO4J_AUTH=none
      - SQLITE_PATH=/app/data/phoenix.db
    depends_on:
      neo4j:
        condition: service_healthy
    command: uv run uvicorn core.main:app --host 0.0.0.0 --port 8000 --reload

volumes:
  neo4j_data:
```

Note: Neo4j healthcheck uses `wget` on the HTTP browser port (7474) — avoids `cypher-shell` auth issues with `NEO4J_AUTH=none`.
